# Included Starlink Traces

This directory contains the fixed 30-session trace set used by the dash.js
experiment: 10 traces each from the US, OSN, and VIC groups. The traces are
processed from the [StarNet dataset](https://github.com/ConnectedSystemsLab/StarNet).

Each file contains elapsed time in seconds and throughput in Mbps. See
[`docs/DATASET.md`](../../docs/DATASET.md) and
[`data/manifests/evaluation_holdout30.csv`](../manifests/evaluation_holdout30.csv)
for provenance, selection, and per-trace metadata.
